玩法说明

🎯 目标

  • 全灭（Rout）：消灭所有敌方单位
  • 占领（Seize）：占领敌方王座/据点（站在上面 2 回合）
  • 到达（Reach）：指定单位到达目标格
  • 坚守（Defend）：坚持 N 回合存活，回合结束时存活方获胜
  • 组队模式：同一队伍的玩家共享胜负判定

🗺️ 地形

  • 平地（浅绿）：移动消耗 1，无加成
  • 森林（深绿）：移动消耗 2，防御 +2
  • 山地（灰）：移动消耗 3，防御 +3
  • 河流（蓝）：移动消耗 3，无加成
  • 城堡（金）：防御 +5，不可被敌方占领后踏入

⚔️ 单位

  • 剑士 ×2：物理，攻防均衡，近战，移动 3
  • 弓箭手 ×1：物理，远程（射程 2），低防，移动 3，技能【狙击】（+1 射程），不能攻击 1 格
  • 骑士 ×1：物理，高移速（5），高攻，低防，技能【连击】（攻击 2 次，每次 50% 伤害）
  • 术士 ×1：魔法，均衡型，射程 1-2，技能【暗影波】（范围攻击）
  • 治疗师 ×1：魔法，可治疗相邻友军 20HP，魔攻稍低

📐 回合流程

  1. 服务器生成地图和单位
  2. 当前玩家可无限次移动/攻击/技能/待命
  3. 点「结束回合」→ 下一玩家
  4. 所有玩家结束 → 服务器结算（升级、清除阵亡）→ 下一回合

💥 战斗公式

物理伤害 = ATK × (ATK / (ATK + DEF + 地形)) × 克制 × 暴击

魔法伤害 = MATK × (MATK / (MATK + MDEF + 地形)) × 克制 × 暴击

  • 攻击类型取决于攻击方的类型（物理/魔法）
  • 克制：剑士→骑士(+20%)，骑士→弓箭手(+20%)
  • 暴击：基础 5% + 每级 1%，伤害 1.5 倍
  • 士气：每星 +10% 攻 / +5% 防，上限 3 星
