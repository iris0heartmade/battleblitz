## 当前阅读顺序

1. [`路线/项目状态.md`](路线/项目状态.md) - 当前基线、分支归档、完成度评估、下一步建议。

## 文档维护规则

- 当前状态只更新 `路线/项目状态.md`,不要再新增多个“状态报告”。
- 历史计划放在 `superpowers/` 或 `维护/审计/`,不要当当前路线入口。
- 新增主线/FE-like 设计时,先在 `路线/项目状态.md` 登记结论,再链接到详细设计。
- 文件路径使用相对路径,避免写本机绝对路径。
