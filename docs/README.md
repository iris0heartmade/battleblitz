## 文档维护规则

- **当前状态只更新 [`路线/项目状态.md`](路线/项目状态.md)**，不要新增多个"状态报告"。
- **当前事实只写在** `../README.md` + `路线/项目状态.md` + `架构/架构.md` 三份里，其余文档引用它们，不要复制一份。
- 专题文档若记录的是**某一时点的快照**，必须在开头写明记录日期与「已封档/已过期」标记。
- 待办类文档必须标明**是否仍未完成**。
- 历史计划放 [`superpowers/`](superpowers/) 或 [`规划/`](规划/)，不要当当前路线入口。
- 文件路径使用相对路径，避免写本机绝对路径。
- 详细规范见 [`规范/文档存放规范.md`](规范/文档存放规范.md)。
