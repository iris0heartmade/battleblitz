## 1. 交付结构

```text
正式 Godot 客户端
├─ visual_tokens：统一颜色、间距、控件状态与继承主题
├─ page_style：页面入口、旧装饰移除、设置暂停与顶部样式
├─ menu / mainline / battle themes：各用途的共享组件样式
└─ landscape_hud：通透地貌中层与单位信息前层
   ├─ terrain_hud：六套原创透明地貌
   ├─ 单位 / 空地 / 移动目标 / 战斗预测状态
   ├─ 保留原攻击与取消按钮路径和业务信号
   └─ 详情抽屉、地图镜头安全区与底栏点击阻挡
```

## 2. 页面覆盖

统一入口菜单、连接、主线档案与章节、备战及英雄/部队/装备/佣兵/商店共用页签、大厅/建房/房间、存档、进行中、设置、暂停、剧情对话、战斗结算、战报及地图编辑器。沿用现有业务流程和人物资源，不新增玩法或战斗公式。

公共控件统一默认、悬停、按下、禁用和键盘焦点状态。去除顶部厚金属图和命名旧装饰相框，主线纸面摘要提高对比度，收紧面板留白并扩大列间距。默认主题显示名为“轻量军议”，既有内部标识不变。

战场不再常驻左右巨型框，单位信息转入底栏，指挥官/任务等通过详情展开。预测不再叠中央大框，右下保留原确认/取消按钮，服务端预测压缩为四行并在1280宽窗口完整显示。

## 3. 素材与数据

六类中层：草原、森林、岩地、沙地、水岸、城镇。均为2172×724 RGBA PNG，检查Alpha范围0～255，具有真实透明区域。自然地貌中间低、两侧高，城镇采用中央建筑，透出后方地图。提示词和生成方式保存在 `godot-client/assets/ui/terrain_hud/GENERATION.md`，草原首稿提示词在同目录 README。

MP 是本游戏移动力：底栏显示真实剩余移动力/移动能力，保留0.5，不新增独立法力值。地形栏显示基础进入费用，不把它冒充包含上坡、飞行和路径修正后的实际总费用。高差攻击/射程只在具体目标预测中出现；缺失值显示“—”。

未知地形使用草原构图降级但不伪装地形名称；城门、雪峰有对应素材映射。半点移动、取消模式和单位清理有单独检查。

额外检查底栏文字处真实点击由底栏接收，不向棋盘传递移动指令；详情按钮仍可使用；预测正文不超过可用高度。状态测试带20秒失败退出兜底。

最终实机截图位于 `output/ui-refactor-2026-11-13/screenshots/`，每个分辨率保留选中、移动到森林、预测、取消、攻击后五阶段。主线、暂停等截图只用于视觉核验，不代替业务流程验收。历史 UI review 工具部分选中截图使用不完整模拟数据，不作为新底栏选中验收证据。

## 5. 边界与后续维护

- 本轮覆盖正式 Godot 客户端；旧 Web 客户端不在本轮改造范围。
- 测试完成不代表穷举每种战斗技能和每张地图；本轮围绕视觉、底栏状态、入口及移动攻击闭环验证。
- 旧二维图源原本漏登记岩地，现补图源登记和山地兼容资源，地图预览与回归检查可正常解析；不改变三维地形或战斗数值。
- 无头像使用既有职业资源与缺失处理；未批量重画玩家角色。
- 所有生成地貌已保存到项目，未只留在生成缓存；原图未覆盖删除。用户已有未提交地图和设计文件保留。
