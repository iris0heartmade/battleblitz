## 0. 设计原则

1. **Generic 单位(普通剑士、弓手、骑士、术士、治愈)**:
   - ❌ 不升级、不成长
   - ✅ 章节难度乘子(atk/def/HP/income/move/vision/recruitCost/levelOffset)
   - ✅ 玩家/敌方可差异化(`campaign_tier` "玩家练"/"敌新兵")
2. **Hero 单位(安娜、云、Seth 等命名角色)**:
   - ✅ 升级 + FE8 风格 7 项成长(HP/Pow/Skl/Spd/Def/Res/Lck %)
   - ✅ 转职线(T1 → T2 → 部分 T3)
   - ✅ 装备 / 技能 / 转职 bonus
3. **12 个兵种**(原 5 + 7 新增),参考 FE8 的 17 个核心职业映射
4. **章节 multiplier** 走 FreeWars 6 旋钮模式(参考 `docs/路线/fireemblem8u-借鉴报告.md` §9)

## 3. Generic 单位 Spawn 公式

```
final_stat = floor(
    base_stat
    × (1 + chapter_modifier / 100)  # 章节 atk/def/income/move 等乘子
    + chapter_level_offset * 5      # 等级"自动加成"
)
HP_cap = 60 + chapter_tier_bonus(玩家)  # cap 也可调
```

**Generic 没有 HP/MP/MP_max 概念**(只有 Atk/Def 决定战斗),**没有 Lv** — 一行清清爽爽。

### 3.1 章节 modifier 模板

```python
class ChapterDifficulty:
    """FreeWars-style 6-knob system (per-chapter config)."""
    attack_modifier: int = 0         # 敌方 attack +% (例: +20)
    defense_modifier: int = 0        # 敌方 def +%
    income_modifier: int = 100       # 玩家收入系数(80=收入 -20%)
    move_range_modifier: int = 0     # 敌方 mov +N
    vision_modifier: int = 0         # 敌方视野 +N
    level_offset: int = 0            # 敌方基础值 +N 级(autolevel 撑数值)
    max_recruit_count: int = 5       # 玩家本章最大可招
    recruit_cost_multiplier: int = 100 # 招募费用系数
    starting_fund: int = 1000        # 玩家起始资金
```

### 3.2 Player/Enemy 差异化(`campaign_tier`)

| Tier | 描述 | 数值修饰 | 适用 |
|---|---|---|---|
| `veteran` 老兵 | 玩家主线单位 | base × 1.10 + +5% HP | player 招募类 |
| `regular` 标准 | 普通玩家单位或低阶 enemy | base × 1.0 | player 副招募 / 默认 enemy |
| `recruit` 新兵 | 早期关卡 enemy | base × 0.85 + cap 50 HP | chapter 1-2 enemy |

`campaign_tier` 是 unit spec 的字段:
```python
class GenericUnitSpec:
    type_id: str                # "swordsman"
    tier: Literal[1, 2]         # T1 = soldier, T2 = promoted
    campaign_tier: Literal["veteran", "regular", "recruit"]
    base_hp, base_atk, base_def, base_mov, base_mp_pool: int
    attack_range_min: int
    attack_range_max: int
```

## 4. Hero 模板(10 个命名角色)

> 沿用现有 `HeroCharacterTemplate` + `HeroClassTemplate` 数据类(已经存在)。
> Hero 通过 `hero_campaign_state` 跨战斗持久化(Lv / 装备 / 技能 / 转职)。

### 4.1 Hero L1 = "打过 4 仗"的状态

**关键校准**:Hero L1 的基础数值 = `class.base + 3 × growth/100`(rounded)。

→ Hero 出场时已经吃 3 次成长的收益(等效 FE8 L4)。不是 L1 新兵,而是"小有名气的雇佣兵 / 公主的随从"。

```
Hero 出场水平           跟 Generic L1 对比
──────────────────────────────────────────────
Hero L1 = FE8 L4 expected ≈ Generic L1 × 0.85
Hero L10 = FE8 L10 expect ≈ Generic L1(持平)
Hero L20 = FE8 L20 expect → Generic L1 × 1.5 反超
```

→ 早期 Hero 比 Generic 弱,**中后期反超** —— 玩家"养号"投资有意义。

### 4.2 Hero 升级公式(FE8 风格)

```python
def roll_growth(growth_rate: int) -> int:
    """Per-level: growth > 100 → guaranteed +1 then re-roll remainder.
    Average = growth / 100 per level."""
    gain = 0
    g = growth_rate
    while g > 100:
        gain += 1
        g -= 100
    if random.randint(0, 99) < g:
        gain += 1
    return gain

# Hero L1 base = class.base + 3 × class.growth / 100
# Then L4+ rolls per-level (linear per stat, see §4.3 below).
```

## 6. 我方差异化策略

> 用户要求:"玩家有的单位强于敌方,有的弱于敌方"。

### 6.1 玩家单位强项(`campaign_tier = veteran` + bonus)

| 单位 | 比敌方的优势 | 限制 |
|---|---|---|
| Swordsman | +10% Atk、+5 HP cap | Def 持平(易被重装打死) |
| Archer | AtkRng +1(3-4 vs 敌方 2-3) | HP 极少(被近战一击) |
| Knight | +5 HP cap、+1 Mov | Spd 慢(被剑圣/枪骑抓) |
| Warlock | MAtk +10%、暴击 +5% | Def 低、不带治愈 |
| Healer | 治愈范围 +1、MP +20% | Atk 弱 |

### 6.2 玩家单位"有意做弱点"

- Swordsman: 缺 Lck,被 Boss 暴击率比敌方高
- Knight: Spd 6(Seth 同档,但不会被升级)
- 整体: **没有装备 / 没有转职**(普通单位转职需"团长之路"XP 攒够 1000,**很慢,作为长期目标**)

### 6.3 Enemy 强化策略(`campaign_tier = regular` 或 `recruit`)

- Enemy Lv = 默认 1 + chapter `level_offset`(早期 0、晚期 +5)
- 数值上 `base × (1 + chapter.attack_modifier / 100)` + `level_offset × 5`
- **Enemy 不成长**(战斗结束 HP 回到 status quo,新章节重新计算)
