## 1. 章节顶层字段(13 个)

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | str | ✅ | 唯一 ID, `chapter_NN_<slug>` |
| `title` | str | ✅ | 中文标题 |
| `synopsis` | str | ✅ | 一句话剧情简介,UI 列表显示 |
| `cover_art` | path | ⚪ | 封面图相对路径 |
| `background` | str | ⚪ | 章节背景描述(纯文本,UI 在 synopsis 下方) |
| `tags` | list[str] | ⚪ | 标签,便于筛选: `boss_battle` / `siege` / `defend` / `paralogue` / `side_story` |
| `preconditions` | object | ⚪ | 解锁条件(见 §5) |
| `required_classes` | list[str] | ✅ | 玩家必须带的兵种 |
| `deployment_cap` | int | ⚪ | 出场名单上限 |
| `forced_heroes` | list[obj] | ⚪ | 强制出场的英雄(按 hero_id) |
| `starting_units` | list[obj] | ✅ | 章首玩家编队 |
| `rewards_on_clear` | object | ✅ | 通关奖励(见 §6) |
| `tactics_rank` | object | ⚪ | 评分阈值 `{S:8, A:12, B:18, C:30, D:999}` |

## 2. 战斗字段(15 个)

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | str | ✅ | `battle_NN` |
| `title` | str | ✅ | 中文战斗名 |
| `map_id` | str | ✅ | 现有地图 ID 之一(见 `MAP_PRESETS`) |
| `map_seed` | int | ✅ | 地图随机种子 |
| `win_condition` | enum | ✅ | `rout` / `seize` / `reach` / `defend` / `boss` |
| `turn_limit` | int | ⚪ | 回合上限(超过自动 fail) |
| `fail_if_hero_dies` | list[str] | ⚪ | 阵亡即失败的 hero_id 列表 |
| `weather` | str | ⚪ | `rain` / `fog` / `snow` / `clear` |
| `fog_of_war` | bool | ⚪ | 是否开战争迷雾 |
| `teams` | object | ✅ | `{ally: [...], enemy: [...]}` |
| `enemy_commander` | str | ⚪ | 敌人指挥官(需在 heroes 注册表里,NPC 敌人填 `null`) |
| `boss_unit_id` | str | ⚪ | `win_condition=boss` 时必填,标识 boss 角色 |
| `waves` | list[obj] | ⚪ | 援军波次,见 §3 |
| `traps` | list[obj] | ⚪ | 地图陷阱,见 §4 |
| `battle_talks` | object | ⚪ | 本战场内战斗对白,见 §7 |
| `defeat_hero_dialogue` | str | ⚪ | 关键角色阵亡时触发的对白路径 |
| `mid_battle_trigger_turn` | int | ⚪ | 战斗内触发对白的回合 |
| `mid_battle_trigger_dialogue` | str | ⚪ | 触发对白路径 |
| `pre_battle_dialogue` | str | ⚪ | 战前对白(默认 `intro`) |
| `post_battle_dialogue` | str | ✅ | 战后对白(对应 `dialogues["battle_NN_after"]`) |
| `spawn_overrides` | object | ⚪ | 单位级调整,见 §8 |

## 3. 援军波次 `waves[]`

```json
{
  "turn": 3,
  "spawns": [
    {"x": 12, "y": 0, "type": "knight", "color": "blue", "level": 3}
  ],
  "trigger_msg": "援军从北坡冲下!"
}
```

- `turn` 从 1 开始(玩家第 1 回合)
- `spawns` 单位属性同 `starting_units`
- `trigger_msg` UI 在波次触发时显示给玩家

## 4. 地图陷阱 `traps[]`

```json
{
  "x": 8, "y": 4, "type": "spike", "damage": 8, "trigger": "step",
  "duration_turns": 3
}
```

- `type`: `spike` / `poison` / `teleport`(待扩展)
- `trigger`: `step`(踩到触发) / `turn_start`(回合开始触发)
- `duration_turns`: 持续回合数(poison 类需要)

## 5. 解锁条件 `preconditions`

```json
{
  "completed_chapters": ["chapter_05_crown_united"],
  "required_heroes_alive": ["yun", "anna"],
  "min_support_pairs": [{"a": "yun", "b": "anna", "min_level": "B"}],
  "min_gold": 800
}
```

- `completed_chapters`: 通关过的章节 ID 列表
- `required_heroes_alive`: 必活的英雄
- `min_support_pairs`: 支援等级下限(M6/支援系统上线后生效)
- `min_gold`: 玩家需要持有最少金币

## 6. 通关奖励 `rewards_on_clear`

```json
{
  "gold": 1500,
  "exp_per_unit": 250,
  "items": [{"item_id": "hero_crest", "count": 1}],
  "unlock_class": "knight",
  "unlocks_chapter": "chapter_07_dawn_reckoning"
}
```

- `gold`: 队伍奖励金币
- `exp_per_unit`: 每名单位经验
- `items`: 道具列表
- `unlock_class`: **单字符串**的职业解锁(注意:不是 list)
- `unlocks_chapter`: 解锁的下一章 ID

## 7. 战斗对白 / 支援对白

```json
"battle_talks": {
  "yun_vs_kalde":   "stories/chapter_06/battle_talk_yun_vs_kalde.json",
  "anna_vs_priest": "stories/chapter_06/battle_talk_anna_vs_priest.json"
},
"support_dialogues": {
  "yun_anna_c": "stories/chapter_06/support_yun_anna_c.json",
  "yun_anna_b": "stories/chapter_06/support_yun_anna_b.json"
},
"defeat_talks": [
  {"hero_id": "yun", "msg": "云: 路, 就到这里了吗",
   "event": "stories/chapter_06/defeat_event_yun.json"}
]
```

- `battle_talks` 键格式: `<hero_a>_vs_<hero_b>`
- `support_dialogues` 键格式: `<hero_a>_<hero_b>_<level>` (c/b/a/s)
- `defeat_talks` 是数组,每项含 `hero_id` + `msg` + `event` 路径

## 8. 单位级 `spawn_overrides`

```json
{
  "add": [
    {"x": 14, "y": 2, "type": "sniper", "color": "blue", "level": 5}
  ],
  "replace": [
    {
      "match": {"color": "blue", "x": 7, "y": 7},
      "unit":  {"type": "knight", "color": "blue", "level": 20, "name": "kalde",
                 "is_boss": true, "stats_override": {"hp": 80, "atk": 28, "def": 18}}
    }
  ],
  "remove": [
    {"color": "blue", "x": 12, "y": 9}
  ]
}
```

## 10. 多难度调节

```json
"difficulty_modifiers": {
  "easy":   {"level_delta": -1, "gold_bonus": 0.30, "enemy_hp_mult": 0.85, "reinforcement_turn_delay": 3},
  "normal": {"level_delta":  0, "gold_bonus": 0.00, "enemy_hp_mult": 1.00, "reinforcement_turn_delay": 0},
  "hard":   {"level_delta":  1, "gold_bonus": 0.00, "enemy_hp_mult": 1.15, "reinforcement_turn_delay": -2}
}
```

- `level_delta`: 敌人最终等级偏移
- `gold_bonus`: 通关奖励乘数
- `enemy_hp_mult`: 敌人 HP 倍率
- `reinforcement_turn_delay`: 援军波次延迟回合(正数=更晚,负数=更早)

## 11. 强制出场 `forced_heroes` / `forced_deployments`

```json
"forced_heroes": [
  {"hero_id": "yun",  "class_id": "warlock", "level": 12, "name": "云",   "color": "red", "x": 3, "y": 11}
],
"forced_deployments": [
  {"hero_id": "yun",  "chapters": ["chapter_06_iron_reckoning"]}
]
```

- `forced_heroes` 决定本章哪些 hero 必须出现在 starting_units 里
- `forced_deployments` 是全局配置,某 hero 在哪些章节必出
- 注意当前 Pydantic 校验 `hero_id='yun'` 只能绑定到 `class_id='warlock'`(原始职业), 转职类职业在 hero promotion 阶段处理

## 13. 已知约束(07-21 实测)

- `map_id` 必须在 `MAP_PRESETS` 列表里(目前 14 个)
- `class_id` 必须在 classes/units 注册里(目前 7 个: archer/knight/warlock/healer/sniper/...)
- `hero_id` 必须是注册过的 hero(目前: yun/anna)
- `enemy_commander` 必须是 hero,不能填 NPC 敌人
- `track_id` 必须在 `battle_audio.json` 里(目前 1 个: sample_battle_01)
- `unlock_class` 是**单字符串**, 不是列表
