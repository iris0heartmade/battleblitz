## 三、关键变更

### 3.1 后端 P1 — 字段重划(`save/service.py`)

`_PROFILE_SNAPSHOT_FIELDS` 拆成"档案态(随档)"与"账户态(不进 snapshot)":

```python
_PROFILE_SNAPSHOT_FIELDS = (
    "hero_campaign_states", "mercenary_roster_state", "hero_inventory",
    "gold", "unlock_points", "mainline_commanders",
)
```

**新增** `unlock_points`(补 H1 串档隐患)。**移除** `rating`、`unlocked_classes`、`unlocked_cosmetics`、`unlocked_commanders`、`current_season`(load 不覆盖 → 解锁永久)。

游标 `active_mainline` + `mainline_progress` 单独处理(78-83, 103-106 行)。

### 3.2 后端 P2 — 删章节锁

删除三个生产调用面的章节锁:
- `battle_lifecycle.py:462` — start 硬锁
- `prepare.py:92` — GET prepare 硬锁
- `chapters.py:78-84` — `/mainlines` 列表软过滤(改为显示全部 + cleared 标注)

清理 helper:`_ensure_test_mainline_unlocked`、`_current_mainline_for_user`、`_current_test_mainline_for_user`。

保留 `CAMPAIGN_CHAINS`(供 UI 分组)+ `_has_cleared_mainline`(只读 cleared 查询)。

### 3.3 后端 P3 — advance 顺序统一(`battle_lifecycle.py`)

**之前**:auto-save → apply 奖励 → mark_scene_done(cursor 推进)
- snapshot.cursor = 推进前(不一致)

**之后**:apply 奖励 → mark_scene_done(cursor 推进) → auto-save
- snapshot.cursor 与 slot.chapter_index 都是 `next_index`(单一真相)
- "载入结束档 = 准备打下一章" ✓

### 3.4 后端 P3 — start 重复写清理

`/start` 端点删除 try/except 后多余的:
```python
profile.active_mainline = ...
profile.mainline_progress = ...
await session.flush()  # ← 删(冗余)
```
后续 `session.execute(update(...))` 是显式 UPDATE 唯一一次写入。

### 3.5 后端 P3 — 平行 API 标 deprecated(`profile.py`)

`/profile/{user}/mainline/{start|advance|abandon}` 标 deprecated(文档性)。
这些路由直接写 profile 全局游标,绕过 SaveService SoT。新调用方应走 `/mainlines/...`(`battle_lifecycle.py`),FE 已切换。

### 3.6 前端组件化 — saves_controller

`godot-client/scripts/ui/saves_controller.gd`(~370 行):
- 20 个函数搬入
- `var _main: Node`(注入,跨域访问 `_user_name` / `_active_mainline_id` / `_show_view` / `_update_status` 等)
- helper(`_save_records_from_response` / `_format_save_name` / `_save_option_label`)权威放在 saves_view
- main.gd 减少 ~360 行

### 3.7 前端组件化 — mainline_controller
