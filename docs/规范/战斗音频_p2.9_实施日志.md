## 3. 阶段 B · track_id 注册校验

### 3.1 变更
- 新异常 `UnknownBattleTrackError(KeyError)`,带 `track_id` 和 `available` 列表。
- `expand_battle_config(raw, strict=False)`:
  - `strict=False` (默认):未知 track 仍合并全局 defaults,跳过 per-track overrides(向后兼容)。
  - `strict=True`:未知 track 抛 `UnknownBattleTrackError`。
- `BattleSpec._check_bgm_track`(Pydantic `model_validator(mode="after")`):校验 `battle_config.audio.bgm.track_id` 在注册表中,缺失抛 `ValueError` → 翻译为 `MainlineValidationError` → HTTP 422。
- `app/routes/game.py::create_game` 通过新 helper `_expand_user_battle_config(battle_config)` 用 `strict=True` 展开,捕获 `UnknownBattleTrackError` 转 HTTP 400,`detail` 含可用 track 列表。

### 3.2 关键行
- `game/app/battle_config.py:50-66` — `UnknownBattleTrackError`
- `game/app/battle_config.py:69-105` — `expand_battle_config(strict=...)`
- `game/app/mainline/schemas.py:155-180` — `BattleSpec._check_bgm_track`
