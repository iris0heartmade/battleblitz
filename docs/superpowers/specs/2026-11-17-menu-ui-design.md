## 1. 现状与目标
已运行现有 ui_review_screenshot 场景并查看主线档案、装备页实际渲染。当前页面大面积使用相同深色外框、三栏容器与浅色文字板。中央信息以段落拼接，角色和装备缺乏主体；任务摘要与操作指南占据整列，层级重复。

目标：一眼看见当前页面的主体、当前选择及下一步。保留已认可的战场底栏，改造主菜单、主线档案与整备、对战大厅、存档、进行中、设置、暂停、帮助及编辑器菜单外壳。完整覆盖既有入口，不增加无后端支撑的养成系统。

## 2. 页面与调用结构
```text
全局菜单系统
├─ 公共视觉配置：色彩、字号、间距、选中/焦点/禁用状态
├─ 页面外壳：背景 → 标题与路径 → 主体 → 底部操作
│  ├─ 叙事入口：主菜单、主线档案、章节详情
│  ├─ 军议整备：英雄、部队、装备、佣兵、商店
│  └─ 管理页面：大厅、存档、进行中、设置、帮助
├─ 浮层：确认、错误、暂停；统一遮罩和返回行为
└─ 原有控制器：读取真实资料、提交操作、显示结果
```
公共主题由 visual_tokens、menu_theme、mainline_theme、page_style 的现有入口衔接。页面专属布局留在各场景/面板，避免主控制器继续堆叠样式逻辑。公共菜单主题不得无差别覆盖已认可的战场底栏。

## 3. 视觉系统
- 深靛蓝导航 #182332，暖白内容 #EEEADF，正文墨色 #273343，哑金强调 #B59B68。红色仅用于危险操作或明确负收益；绿色用于正收益与成功。
- 背景保留场景气氛，阅读区域用稳定实底或渐变衬底；背景不能隔着小字干扰阅读。
- 以 1920×1080 为设计基准，标题40、分区24、正文20、次级18；1280×720 独立调整布局与字号，避免只整体缩小。
- 当前选项使用左侧金色标记、底色与文字三重区别；键盘焦点单独画细框，不能与选中状态混同。
- 面板有主次：页面壳无粗重外框，信息分区用留白与分隔线，仅选中行和确认浮层强调边界。
- 各页共享顶部标题/返回路径和底部操作基线；不用多个竞争的主按钮。

## 4. 逐页布局
| 页面 | 主体设计 | 操作与小窗口处理 |
|---|---|---|
| 主菜单 | 左侧游戏标题与纵向主要入口，右侧保留背景主角；次要工具放底部 | 继续旅程/主线战役/自由对战明确分级；加入代码移到联机页；已有入口保持可达 |
| 主线档案 | 左侧紧凑档案列表，中央章节大标题、真实进度、角色肖像与下一战简报 | 取消常驻整列操作指南；底部只突出进入战役；空档说明新开旅程，删除单独确认 |
| 章节详情 | 章节编号、标题、目标摘要和地图预览构成主体；队伍摘要压缩为横条 | 没有真实预览时显示明确空态，不放伪造地图 |
| 战前整备 | 顶部英雄/部队/装备/佣兵/商店页签；主区随任务改变，任务摘要折叠到顶部入口 | 底部固定返回、完成整备、开始战斗；危险的放弃操作收进确认流程 |
| 英雄 | 左侧带头像名册，中间较大立绘与身份，右侧紧凑属性及技能 | 无头像时有稳定占位；不让空立绘挤走关键属性 |
| 装备 | 左侧英雄名册，中间三个真实槽位与候选物品列表，右侧选中装备详情与当前装备对照 | 替换大下拉框；数量、可装备条件、当前/候选清楚分列；没有计算依据不显示虚构属性增益 |
| 部队/佣兵 | 名册列表与选中单位详情，部署数量/点数汇总位于标题下 | 已部署、可部署、不可用分别标记；沿用现有部署和招募规则 |
| 商店 | 物品列表展示图标、名称、库存与价格；右侧物品说明、购买对象/条件 | 金币常驻；购买按钮显示当前操作；未返回成功不得提前显示购入成功 |
| 大厅 | 创建、加入、房间详情分层；房间中玩家席位与地图预览作为主区 | 地图/规则设置独立分组；连接中和重试不与空房间混淆 |
| 存档/进行中 | 行式档案呈现章节、日期、阵容与状态；右侧仅显示所选记录详情 | 载入为主操作；删除为次级危险操作 |
| 设置/帮助 | 左侧分类，右侧紧凑设置行或分组说明，避免满屏按钮矩阵 | 保留应用、取消语义；返回时处理已有未保存状态 |
| 暂停/确认 | 背景压暗，居中紧凑卡片；一次只处理一个决策 | 焦点进入浮层，关闭后回到原按钮；遮挡区域不能点击穿透 |
| 编辑器菜单外壳 | 顶部工具分组，属性区按地形/高度/地物分类，保存和测试突出 | 保留地图操作与棋盘规则；不改地形底座美术 |

## 5. 状态与交互
- 实际资料、选择、加载、空态、失败与禁用都各自有明确呈现；工具截图中演示资料不得混入真实存档。
- 悬停、键盘焦点、选中、按下、禁用要在鼠标和键盘下均可区分。
- 切换英雄/装备后同步更新详情；旧请求不得覆盖新的选择；重复提交要禁用相关按钮直至结果返回。
- 长名称允许省略并提供全文说明；正文容器允许滚动，底部主操作不得被挤出屏幕。
- 1280 下名册收窄、立绘缩小、非关键说明折叠；属性和确认操作必须保留。1920 下避免文字被拉成跨屏长行。
- 轻量切换动效建议120–180毫秒，只在已有设置允许时使用；退出页面结束动画，不创建常驻后台循环。

5. 回归已认可的战场底栏和窗口调整；更新中文 CHANGELOG，区分截图检查与实际功能验收，保留未完成项。

风险：既有控制器引用场景节点路径；优先保留被引用节点与信号，新增容器时同步排查引用。部分界面存在不同主题入口重复覆盖，应明确覆盖顺序；不能仅添加第三套样式。截图工具使用模拟数据，只能证明布局，不足以证明装备、购买和存档写入成功。
