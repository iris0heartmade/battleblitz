## 这里面是什么

`specs/` 与 `plans/` 是 BattleBlitz 各个功能在**设计阶段**产出的文档：

| 目录 | 篇数 | 内容 |
|---|---:|---|
| `specs/` | 27 | 功能设计（做什么、为什么、规则细节）|
| `plans/` | 25 | 实施计划（分几步做、每步改哪些文件、怎么验收）|

它们的价值是回答一个问题：**「当初为什么这么设计」**。比如「为什么克制倍率是 1.20 而非 1.5」「为什么 MP 用双倍制」，答案在这些文档里，而不在当前代码注释里。

## ⚠️ 使用须知

1. **内容停留在编写当时**，普遍是 2026-07（少数到 08），此后代码已大幅演进。
2. **数字大概率已过时**。例如 UI V2 设计、CO 能量设计等文中的行数、模块数、兵种数与当前代码不符。
3. **大多数设计已实现**，但实现细节与原文会有出入——以**代码**为准。
4. 少数设计**最终未采用**（例如 07-16 版 parity 审计被 07-17 版取代）。
