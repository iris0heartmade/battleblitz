# 主线章节验证测试方案

## 设计目标

根据「主线剧情模板化」的 14 个可魔改维度，验证**典型主线章节的完整生命周期**是否能跑通。

## 典型主线生命周期

```
[章节JSON] → [Schema验证] → [前置条件检查]
     → [准备阶段: 英雄/装备/转职/佣兵]
     → [开始战斗: spawn_overrides + hero_states]
     → [战斗循环: 波次/陷阱/Boss/对话/胜利判定]
     → [战后: 英雄成长保存/下一场/商店]
     → [最终胜利: 奖励发放/下一章解锁]
```
