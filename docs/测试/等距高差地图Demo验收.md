## 3. 复现方式与限制

```powershell
# 在仓库根目录执行，替换引擎路径
& '<Godot程序路径>' --headless --path godot-client --script res://demos/height_map/verify.gd
$env:BB_HEIGHT_SCREENSHOT = Join-Path $PWD 'logs\height-demo-1920.png'
& '<Godot程序路径>' --path godot-client --rendering-method gl_compatibility --resolution 1920x1080 --script res://demos/height_map/verify.gd
& '<Godot程序路径>' --headless --path godot-client res://tools/smoke_test.tscn
```

当前独立Demo已支持基础同机双人战斗，沿用原地形移动与攻击规则。高度仍仅用于表现，未加入爬坡消耗、跳落规则、高低差射程或正式山脉美术；技能、治疗、招募、占领和AI尚未接入本Demo界面。没有移除旧系统，也没有把新高度写进旧地图协议。

战斗验证可由启动器自动准备独立服务并在完成后关闭：

```powershell
powershell -NoProfile -File tools/run_height_demo.ps1 -VerifyBattle
# 日常打开可双击根目录“高差地图Demo.bat”，点击“开始试战”。
# 仅离线地图预览：
powershell -NoProfile -File tools/run_height_demo.ps1 -PreviewOnly
```

标准图专项命令：

