## 5. 地图设计结构树

```text
战斗地图
├─ 目标层: 为什么玩家要移动
│  ├─ 火纹: 击破 Boss / 压制王座 / 救援 / 访问村庄 / 限时推进
│  └─ 高战: 占 HQ / 抢城市收入 / 抢工厂产能 / 控机场港口
├─ 空间层: 玩家怎么移动
│  ├─ 主路: 最短、最明显、压力最大
│  ├─ 支路: 更慢或更危险, 但给奖励
│  ├─ 瓶颈: 桥、门、山口、浅滩, 控制交战宽度
│  └─ 开阔区: 会战场, 必须配遮蔽/经济点/远程威胁
├─ 地形层: 让路线产生价格
│  ├─ 火纹式价格: 移动力、回避、防御、职业适配
│  └─ 高战式价格: 收入、生产、补给、载具通行
├─ 压力层: 敌人怎样把地图激活
│  ├─ 固定守点: 城堡、工厂、港口、桥头
│  ├─ 机动威胁: 骑兵/飞兵/坦克从开阔地制造追击
│  └─ 分段增压: 开门、过桥、靠近 HQ 后触发新压力
└─ 可读层: 玩家能不能一眼看懂
   ├─ 地形成簇, 不撒芝麻
   ├─ 关键目标提前可见
   └─ 每 5-7 格出现一次有意义选择
```

## 6. 火纹地图学到什么

| 观察 | 地图例子 | 设计意义 | BattleBlitz 可落地 |
|---|---|---|---|
| 城堡不是"室内皮肤", 而是节奏开关 | Castle Renvall、Renais Castle Interior | 门、墙、走廊控制一次暴露多少敌人 | 城堡图优先做"门 -> 小房间 -> 王座"三段结构 |
| 野外大图靠地形簇分区 | Adlas Plains、Bethroen、Darkling Woods | 森林/山/河把大地图切成战术区域 | 生成器输出地形簇, 不要随机撒点 |
| 慢地形要配奖励 | Za'albul Marsh、Hamill Canyon | 玩家愿意吃移动惩罚, 是因为支路有收益 | 沼泽/雪原/沙漠支路放村庄、宝箱、招募点 |
| 海岸图强调"边界压力" | Melkaen Coast | 水陆边界限制路线, 也制造侧翼危险 | 若加入船/飞行, 海岸线要服务登陆点和补给点 |
| 早期据点图面积小但决策密 | Bandit Hideout、Fort Rigwald | 小图靠障碍和入口做微型战术题 | 教学关不用大, 只要入口、掩体、敌人站位清楚 |

## 7. 高战地图学到什么

| 观察 | 地图例子 | 设计意义 | BattleBlitz 可落地 |
|---|---|---|---|
| 经济点就是战斗理由 | AWDS Mission 1、Spann Island | 城市/工厂位置决定交战线 | BattleBlitz 村庄/兵营要放在会被争夺的位置 |
| 生产点改变前线形状 | Factory Exterior、Factory Interior | 工厂越靠前, 战线越早爆发 | 兵营不要全塞出生点, 可以做中立前线兵营 |
| 海图需要双阶段目标 | Sea of Hope、Sea Fortress、Moji Island | 先控港/海路, 再上岸或推进 HQ | 未来海战应拆成"控港口 -> 登陆 -> 占内陆" |
| 对称图要有中线冲突 | AWBW A Bridge Too Far、Meet me in the middle | 公平靠对称, 有趣靠中线奖励 | 多人图先画冲突轴, 再摆出生点 |
| 社区图常用小型高密度 | AWBW 多数样本 | 地图虽小, 但经济点和瓶颈很密 | 15x15 内也能做深度, 关键是每 3-5 回合有目标 |

## 8. 共通设计规律

| 规律 | 蠢猪也能懂的解释 | 设计落地 |
|---|---|---|
| 先画冲突轴 | 先决定玩家会在哪里打架 | 每张图标出 1 条主冲突轴 + 1 条侧翼诱因 |
| 地形要有价格 | 走森林/山地/海岸不能只是换颜色 | 给地形绑定移动、防御、经济或视野差异 |
| 支路必须返钱 | 绕远路如果没奖励, 玩家不会绕 | 支路尽头放村庄、兵营、宝箱、招募或高地 |
| 瓶颈不能堵死 | 桥和门是选择题, 不是排队题 | 瓶颈旁加侧门、浅滩、树林或远程反制点 |
| 终点提前可见 | 目标越早看见, 玩家越容易规划 | 王座、HQ、Boss、港口应在地图结构上醒目 |
| 小图也要有阶段 | 小地图也不能一开局就全打完 | 用门、桥、经济点、增援做 2-3 段节奏 |

## 9. BattleBlitz 推荐模板

| 模板 | 结构 | 适用场景 |
|---|---|---|
| 三段城堡 | 外庭开阔 -> 走廊瓶颈 -> 王座房 | Boss 关、章节终战 |
| 双翼夹中 | 中路最短但危险, 两翼慢但有资源 | 早中期野外战 |
| 桥头经济战 | 桥两侧放村庄/兵营, 中线可反制 | 多人、AI 对战 |
| 海岸登陆 | 港口补给 -> 登陆点 -> 内陆目标 | 加船/飞行后 |
| 沼泽/沙漠奖励路 | 慢地形中嵌入稀缺收益点 | 特殊地形章节 |

## 10. 结论

火纹地图强在"职业移动差异 + 章节目标 + 敌人投放"的组合; 高战地图强在"经济点 + 生产点 + 对称冲突轴"的组合。BattleBlitz 不应该只学像素地砖, 而应该学它们的父子结构:

```text
章节目的
└─ 地图冲突轴
   └─ 地形价格
      └─ 收益点
         └─ 敌人/AI 压力
            └─ 玩家每几回合一次的选择
```

下一步如果要把调研变成实现, 建议先给每张主线地图加一份"地图设计卡": 目标、主路、支路、瓶颈、收益点、敌人压力、预计通关回合。这样设计不会散, 后续生成器也有明确输入。
