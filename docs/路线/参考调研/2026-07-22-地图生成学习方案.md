## 2. 学习回路(generate → score → mutate → re-score)

```
        ┌──────────┐    ┌──────────┐    ┌──────────┐
        │  参考图  │───▶│  色板    │───▶│ 自动分类 │
        │  (PNG)   │    │  (JSON)  │    │  (像素)  │
        └──────────┘    └──────────┘    └─────┬────┘
                                              │ features
                                              ▼
┌──────────┐    ┌──────────┐    ┌──────────┐
│ 生成器   │◀───│  fitness │◀───│ 评价函数  │
│ + mutate │    │  score   │    │ quality.py│
└──────────┘    └──────────┘    └──────────┘
     │                              ▲
     │              ┌───────────────┘
     ▼              │
┌──────────┐        │  (想再 score 就跑 check_map_constraints)
│  检查    │────────┘
│  约束    │
└──────────┘
```

**两个 mode**:
- **mode A: 模仿学习** — 用参考图 features 校准 fitness,然后 fitness 反过来监督生成器参数
- **mode B: 约束 + 调参** — 用硬约束(H1/H2/H3)兜底,软分(S1-S6)当目标函数,人工调 `MAP_STYLES` 权重

短期先做 mode B(mode A 要等更多标签数据)。

## 4. P0 调优路线(建议先做这个)

### 4.1 修 FE 风格权重(15 分钟)
**问题**: `config.py` 里 `STYLE_GRASS_OUTER` 的权重是 14 山 / 8 林 / 55 平原,这套是 AW 风格,套到 FE 上完全错。

**改法**: 加一个新的 `STYLE_FE_OUTER`,权重:
```python
TERRAIN_PLAIN:    3,    # 从 55 压到 3
TERRAIN_FOREST:   25,   # 从 14 提到 25
TERRAIN_MOUNTAIN: 50,   # 从 8 提到 50
TERRAIN_RIVER:    8,
TERRAIN_VILLAGE:   5,
TERRAIN_BARRACKS:  2,
TERRAIN_ROAD:      0,    # FE 没路
```

### 4.2 HQ 多格结构(1 小时)
**问题**: 我们的 `build_single_tile_castle` 是 1 格,真图是 3-5 格(尤其 AW)。

**改法**:
- 默认 `use_hq_structure=True`(5x5)
- AWBW 用 3x3 子瓦片(因为 1 个 macro tile = 3×3 = 9 子瓦片,HQ 占 1 个 macro tile = 9 子瓦片)
- 配合 §4.1 调整 HQ 周围地形比例

### 4.3 大水面模板(30 分钟)
**问题**: 河只有 1 格宽,不能像 Sicily / Sea Fortress 那样整片海。

**改法**:
- `river_network.py` 加 `lake_size` 参数,允许生成 5-10 格大水面
- `STYLE_AW_OUTER` 默认 `lake_size=8`

### 4.4 调 S5/S6 metric 阈值(20 分钟)
**问题**: S5/S6 永远是 0,fitness 假性 PASS。

**改法**:
- S5: 改成"每个 HQ 5 格内可见 ≥1 经济点"
- S6: 改成"地图被至少 1 条 ≥8 格的天然屏障(河/山)切分"

## 5. P1 持续优化(有了 P0 之后再做)

### 5.1 per-style target_share
每个 `MAP_STYLES` 加一个 `target_share: Dict[str, float]`(目标地形比例),生成器用模拟退火/遗传算法找参数。

### 5.2 真的从参考图反推(模式 A)
等色板标签够 100+ 样本后:
1. 抽取参考图 features 已有
2. 对每个 kind 算"参考图平均 share" + "目标偏差" 
3. 把偏差作为 fitness 的硬权重

### 5.3 多 HQ 结构 + 出生点
- 多人图 HQ 用 3-5 格结构
- 出生点 vs 中立 HQ 区分颜色

### 5.4 主线(火纹)地图模式
- 加 `win_condition: str`(rout/seize/reach/defend)
- 显式 `objective_tile_id`(单一目标)
- 多回合增援(暂时不做,等用户说)
