# 路线 — 索引

> 项目路线图 + 阶段状态 + 跨分支交接笔记。所有"活在变化中"的进度文档归这里。

## 目录文档

| 文档 | 说明 |
|------|------|
| [`路线.md`](路线.md) | S0 / P0-P3 路线图 + 当前进度标记(✓ / 空白 / 进行中)+ 关键决策索引 |
| [`项目状态.md`](项目状态.md) | 项目状态快照,何时完成 / 进行中 / 待启动;每次大阶段更新时刷 |
| [`交接笔记.md`](交接笔记.md) | 分支间的交接笔记(branch snapshot);用于下一个 agent 上任时快速上手 |

## 维护规则

- 新增文件命名:中文 kebab-case(例:`里程碑.md`)
- `路线.md`:任务实际完成时打 ✓,新任务加 [ ];每次状态变更在文末"最新动向"补一条
- `项目状态.md`:每完成一组 P 阶段或里程碑时刷一次;旧版本用 git log 找
- `交接笔记.md`:每个长生命 feature 分支 push 后刷
- 详细规范见 [`../README.md`](../README.md)
