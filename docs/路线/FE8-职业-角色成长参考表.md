## 0. FE8 成长机制速览

每升 1 级,每项 stat 独立掷骰:g / 100(成长率 X% → X% 概率 +1)。

```
result = 0
while growth > 100:        # 120% → 强制 +1,剩 20%
    result += 1
    growth -= 100
if Roll1RN(growth):         # 再用 X% 概率 +1
    result += 1
return result               # 单次升级可能 0/1/2 点
```

期望单次升级 = growth / 100。**L1 → L20 共 19 次升级**,期望增量 ≈ growth × 0.19。

升级补偿逻辑:全 0 时**优先 HP 补一次**(从 HP→Pow→...→Lck 顺序),最多 2 轮。

转职 L10/L20:累计 base + 转职 bonus + 新 cap,有效经验等级 `+20`(转职后升级比未转职慢)。

## 1. 主干职业成长(按转职线路分组)

> 数字格式 = HP/Pow/Skl/Spd/Def/Res/Lck 7 项成长的百分比(去掉 % 号)。Base 同样格式。
> "转职 bonus"=该 tier-1 → tier-2 时**额外加成**(已经折算到 tier-2 的 base 上,+bonus 是再补一点)。
> 转职等级:tier-1 → L10 转;转职后 (tier-2) 再练到 L20 才可"再转"(但 FE8 大多数 tier-2 不存在 tier-3)。
> Lord 系是唯一三阶路径:Eirika/Ephraim L20 转 MASTER_LORD(tier-2),再 L20(累计 L40)再升 tier-3,可在 §1.6 看。

## 4. 敌方单位"autolevel + class 成长"小兵

FE8 的小兵(弓兵/步兵/剑兵)走 **class 成长 + autolevel**:
- Base 来自 ClassData
- 额外属性累积 = autolevel × class growth(敌人每多 L1,取 class growth 的均值 random)

> 例:敌方一个 L10 fighter-typed sword 单位 → base (L1 stats) + 9 × average(85/55/35/30/15/15/15) → 接近 player L10 fighter 同数值。这意味着**关卡后期敌人不会因为数值"碾压"而失衡**,而是因为种类多样化。

Boss 例外(像 Lobarossa、Bazba、O'Neill):手动给 class + autolevel 数值,**成长全 0**(`85/50/10/10/10/15/30` 这种)— 完全靠"等级"撑数值,玩家打到他时跟玩家 L10 单位同数值。
