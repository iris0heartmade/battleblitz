# 双轨成长重构维护记录

## 背景

2026-08-10 对当前成长系统做审查后确认：仓库中同时存在英雄/佣兵双轨策划、8 月 rolled growth 草案、以及运行时旧升级公式。三者职责混在一起，导致英雄、职业、普通佣兵的成长真源不清。

## 决策

| 项目 | 结论 | 蠢猪也能懂的说明 |
|---|---|---|
| 主方案 | 采用 B. 双轨重构 | 英雄养成和佣兵军备分开 |
| 英雄 | 独立 `character_growth_rates` | 英雄成长看本人，不看职业贴纸 |
| 己方佣兵 | 存档点数强化 | 花资源养兵种，不刷经验 |
| 敌方佣兵 | 章节确定等级 | 关卡策划控制敌人强度 |
| 自由模式 | 默认 Lv10 标准基准 | 快速对战公平，不读主线 |
| MOV | 不随机成长 | 移动力是地图尺度，不能当彩票 |

## 2026-08-10 数值修订

| 项目 | 调整 | 蠢猪也能懂的说明 |
|---|---|---|
| 英雄名 | `yuanying` 展示名统一为“鸢影” | 对外叫鸢影，代码 id 暂可继续沿用迁移前拼音 |
| 新英雄成长 | 白予、林依澜纳入独立成长表，弱侧补到 35% | 新人也得遵守家规，不能偷偷走旧成长 |
| 整体成长 | 非 MOV 成长率整体抬高约 10% | 大家终于不用像饿着肚子打仗 |
| 强侧成长 | 职业/英雄主轴额外提高约 5% | 擅长什么就应该更会长什么 |
| 弱侧攻击 | 弱侧攻击给 35% 起步 | 低是低，不是装死 |
| T2 / 强概念 | 允许成长率超过 100% | 超过 100 的部分就是概率单级 +2 |
| 图表 | 需要用第二版成长表重新生成 | 旧图只保留作对照，不作为最新基准 |

## 2026-08-10 战斗回合校准

| 项目 | 调整 | 蠢猪也能懂的说明 |
|---|---|---|
| 治疗师 | `base_matk 8 -> 12`, `matk growth 25 -> 45` | 奶妈终于不是拿法杖轻轻敲人 |
| 吟游诗人 | `base_matk 10 -> 12`, `matk growth 20 -> 45`, `mov growth 5 -> 0` | 支援也能补刀，但不会变主 C |
| 弓箭手/骑士/龙骑士 | 降低基础 ATK 和/或 ATK 成长 | 压低普通佣兵打英雄的最快击杀线 |
| 剑士/枪兵/战士/天马骑士 | 小幅降低 ATK 成长 | 整体放慢普通 T1 佣兵对英雄的击杀节奏 |
| 测试 | 新增 `test_combat_pacing_calibration.py` | 用击杀次数管住数值手感，不靠玄学感觉 |

## 2026-08-10 会话回顾补漏

| 漏项 | 已补 | 蠢猪也能懂的说明 |
|---|---|---|
| 低成长率残留 | 非 MOV 成长全部不低于 35% | 弱可以弱，不能假装自己没有成长系统 |
| MOV 成长残留 | 所有职业 `mov` 成长清零 | 移动力是地图规则，不是升级彩票 |
| 英雄成长未独立 | 英雄新增并使用 `character_growth_rates` | 云就是云，不再是术士贴一张 modifier 小纸条 |
| 自由模式英雄 Lv10 漏掉 | hero override 后按英雄成长表补 Lv10 标准数值 | 自由模式 commander 不再偷偷退回 Lv1 身板 |
| 自由模式 seed 不明 | 新增稳定 `_spawn_growth_seed` | 同一局同一位置生成结果可复现 |

## 后续

后续如继续扩展英雄或职业，应先更新独立成长表与击杀回合校验，再改生产数据。
