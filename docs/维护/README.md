# 维护 — 索引

> 运维与代码质量文档:死代码扫描 + 各类审计报告归档。

## 目录文档

| 文档 | 说明 |
|------|------|
| [`死代码清单.md`](死代码清单.md) | vulture 扫描结果 + 清理优先级(P0/P1/P2),持续维护 |
| [`审计/`](审计/) | 时间戳命名(`YYYY-MM-DD-<主题>.md`)的审计报告归档,完整项目全景审查 |

## 维护规则

- 新增审计报告必须用日期前缀命名,放进 [`审计/`](审计/) 子目录
- 审计报告之间不强求时序,各自独立
- `死代码清单.md` 在每次代码清理后刷一次
- 详细规范见 [`../README.md`](../README.md)
